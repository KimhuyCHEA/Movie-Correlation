This project explores a movie dataset to identify which factors are most strongly associated with box office success. Using Python and exploratory data analysis (EDA), I cleaned the data, visualized relationships between variables, and calculated Pearson correlation coefficients to uncover trends.

## Objectives

- Clean and prepare the dataset for analysis
- Explore relationships between movie attributes
- Identify variables most correlated with gross revenue
- Visualize correlations using heatmaps and scatter plots

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Features

The dataset includes information such as:

- Movie Title
- Release Year
- Genre
- Budget
- Gross Revenue
- IMDb Score
- Runtime
- Votes
- Director
- Production Company
- Country
